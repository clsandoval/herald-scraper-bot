<objective>
Make `/heralds` the sole entry point to the Herald match board and delete the eternal
always-up board (on_ready channel post + `refresh_board` timer). With no long-lived
board message re-rendering against the DB, the ingest loop can be un-paused in
`Dockerfile.board`. Closes part 1 of issue #4.

Purpose: the always-up board is the root cause of the recurring prod failures
(DB-lock / CPU / memory contention with ingest, dead interactions, OOM). On-demand
removes the whole failure class and lets ingest run continuously again.
Output: an on-demand-only board module, an ingest-restored Dockerfile, updated
regression tests, and a clean working tree.
</objective>
